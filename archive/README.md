# Archive

This folder preserves development evidence without presenting it as production
code.

- `experiments/code/`: frozen challenger implementations and feature searches.
- `experiments/results/`: aggregated metrics used to select the final model.
- `legacy/`: the earlier monthly/parametric solution and its test.
- `notes/`: internal planning, educational walkthroughs, and submission drafts.

Archived scripts may retain their historical paths and are not imported by the
application. The only serving model is in `pipeline/`.
